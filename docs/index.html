Integrity & Security

Zero telemetry. Zero tracking.

YT Blinders runs entirely inside your browser. No external API requests, no user accounts, no hidden metrics.

Only 2 Permissions

Requests strictly storage to save your blinder choices, plus youtube.com host access to apply styles.

Zero Telemetry

No analytics, no beacons, and no tracking scripts. Your viewing patterns stay 100% private to your device.

Audit on GitHub

100% open source under Apache 2.0. Written in clean TypeScript + Vite with Manifest V3 standards.
